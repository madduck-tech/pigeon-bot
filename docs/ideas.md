# Идеи и закрытые механики

Открытые идеи, баги и предложения ведутся только в [GitHub Issues](https://github.com/madduck-tech/pigeon-bot/issues). Новая идея оформляется через шаблон «Идея или новая функциональность»; порядок её анализа и реализации описан в [development-flow.md](development-flow.md).

Этот документ сохраняет только историческую справку о закрытых механиках. Этап 2 с фактом и погодой описан в [design.md](design.md) §7.6.
