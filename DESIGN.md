# Pigeon Bot — дизайн

Статус: черновик v0.1. Это основа для реализации. Изменения решений фиксируем здесь с пометкой «изменено: дата, причина».

---

## 1. Суть

Telegram-бот-шутка для чатов сообщества madduck. Персонаж — голубь, который иногда прилетает в групповой чат, а участники его «плюют»: кнопками, дартсом, дуэлями.

- Бот работает в одном или нескольких групповых чатах. Состояние каждого чата полностью независимо.
- Личных сообщений нет.
- Типичный чат: ~6 участников, низкая активность.

**Цели:** оживить тихий чат и не быть назойливым.

**Не цели (пока):** модерация, распознавание изображений, LLM в ядре механик, глобальный рейтинг между чатами, личные сообщения.

### Персонаж

- Аватар и образ: `assets/pigeon-avatar.png`. Голубь в спортивном костюме, кепке и с золотой цепью, сидит на корточках во дворе. Образ — уличный «гопник-голубь», с подписями и юмором в том же духе.
- Стартовое имя: **Витёк**. Оно звучит по-дворовому, в духе образа. Ежемесячное голосование за имя (§7.8) может его поменять.
- Тон и юмор — дворовый, но без реальных оскорблений участников. Шутки про голубя, ритуал и двор, а не про людей.
- Для публичного аватара в Telegram используем этот же файл. Перед публикацией стоит убедиться, что образ с сигаретой и пивом подходит для чата участников.

## 2. Ограничения Telegram

Проверять по актуальной документации Bot API при реализации: поведение API меняется.

- **Privacy mode.** По умолчанию бот в группе видит только команды и ответы на свои сообщения. Для механики «фото и слово „голубь“» privacy mode нужно отключить (BotFather → `/setprivacy` → Disable). Бот при этом видит все сообщения, но **хранит только метаданные** (время, `user_id`, факт голубиного слова или фото). Текст не сохраняется. Это раскрыто в `/pigeon help`.
- **Права.** Бот — админ чата с правом закреплять сообщения. Нужен для закреплённого дашборда (§8).
- **Миграция в супергруппу.** Меняет `chat_id`. Обрабатываем update `migrate_to_chat_id` и переносим данные.
- **callback_data** — не больше 64 байт.
- **sendDice** — значения 1–6. Для дартса 6 — центр мишени.
- **Опросы** — до 10 вариантов, закрываются по `close_date` или вручную (`stopPoll`).
- **Редактирование сообщений** — ограничено по частоте. Дашборд обновляем не чаще раза в минуту на чат. Ошибку «message is not modified» игнорируем.
- **Сообщения других ботов** бот не видит.

## 3. Мультичат

- Все таблицы содержат `chat_id`. Все запросы фильтруются по нему.
- Чат неактивен, пока админ не выполнит `/pigeon setup`.
- Участник идентифицируется парой `(chat_id, user_id)`. Статистика хранится по чатам. Глобального рейтинга между чатами нет.
- Кросс-чатовые механики (общий квест на несколько чатов) — вне scope.

## 4. Архитектура

**Стек:** Python 3.12, aiogram 3 (long polling), SQLite (`sqlite3` + тонкий слой репозиториев), pydantic-settings для конфига, pytest.

**Слои:**

| Слой | Ответственность |
|---|---|
| `handlers/` | Входящие апдейты: команды, callback_query, dice, poll answers, сообщения с ключевыми словами. Тонкие, без логики. |
| `services/` | Бизнес-логика механик. Не зависит от aiogram, тестируется отдельно. |
| `repo/` | Доступ к SQLite. |
| `scheduler/` | Tick-цикл: раз в ~30–60 с выбирает due-задачи из таблицы `jobs` и выполняет. Переживает рестарт, потому что состояние в БД. |
| `budget/` | Лимиты спонтанных сообщений, тихие часы, проверка «живого» чата. |
| `render/` | Тексты сообщений (шаблоны) и сборка клавиатур. |
| `telegram/` | Адаптер над aiogram: отправка, редактирование, закрепление, опросы. Сервисы не знают про aiogram. |
| `content/` | YAML с контентом (см. §12). |

**Структура:**

```
src/pigeon/
  app.py  config.py
  handlers/  services/  repo/  scheduler/  budget/  render/  telegram/
content/
  jokes.yaml  series.yaml  names.yaml  fortunes.yaml  achievements.yaml  riddles.yaml
tests/
  services/  repo/  handlers/
```

**Время.** Передаётся через clock-объект. В тестах подменяется.

## 5. Модель данных

Все таблицы с `chat_id` — изолированы по чатам.

```
chats(chat_id PK, title, enabled, timezone, quiet_start, quiet_end,
      dashboard_message_id, paused_until, created_at)

pigeon(chat_id PK, name, title, state, born_at, last_arrival_at, arrivals_total)
  state: sitting | flying | away

name_history(id, chat_id, name, from_at, to_at)

events(id, chat_id, kind, status, message_id, opened_at, closes_at, result_json)
  kind: arrival | anniversary | mail
  status: open | closed

hits(id, chat_id, event_id, user_id, created_at, UNIQUE(event_id, user_id))

dart_throws(id, chat_id, user_id, local_day, dice_value, points, UNIQUE(chat_id, user_id, local_day))

bets(id, chat_id, event_id, user_id, choice, stake, payout, status,
     UNIQUE(event_id, user_id))
  status: open | won | lost

trophy(chat_id PK, holder_user_id, since, last_event_id)
trophy_log(id, chat_id, user_id, started_at, ended_at)

members(chat_id, user_id, display_name, username, last_seen_at, PK(chat_id, user_id))

points_ledger(id, chat_id, user_id, delta, reason, ref_id, created_at)
  reason: hit | dart | bet_win | bet_stake | duel_win | quest | achievement | mail

achievements(chat_id, user_id, code, awarded_at, PK(chat_id, user_id, code))

quests(id, chat_id, week_key, target, progress, status)
  status: active | done | failed

series(chat_id PK, season, episode_id, poll_event_id)
series_log(id, chat_id, episode_id, chosen_variant, at)

duels(id, chat_id, challenger_id, opponent_id, state, round, score_a, score_b,
      message_id, created_at, expires_at)
  state: pending | active | done | declined | expired

budget(chat_id, local_day, spontaneous_day, week_key, spontaneous_week, PK(chat_id, local_day))

jobs(id, chat_id, kind, run_at, payload_json, status, attempts)
  status: pending | done | failed
```

**Очки.** Баланс = `SUM(delta)` из `points_ledger` по `(chat_id, user_id)`. Неделя = сумма за период. Отдельных таблиц со счётом нет.

## 6. Ядро: прилёт голубя

1. Scheduler создаёт job `arrival` на случайное время в окне (окно и дневной лимит — в конфиге чата).
2. **Бюджет.** Если спонтанный лимит (§9) исчерпан, job переносится на следующий слот. Не отменяется.
3. **Живой чат.** Если за последние 10 минут написано ≥ 5 сообщений (порог в конфиге), перенос на 15 минут. Максимум 2 переноса, потом отмена на сутки.
4. Бот отправляет:

   ```
   🕊 Голубь прилетел на подоконник. Кто первый?
   ```

   Под сообщением кнопки: `💦 Плюнуть` · `🎯 Дартс` · `💰 Ставка`.

   Создаётся `events` со `status=open` и `closes_at = now + 60 мин`. `pigeon.state = sitting`.
5. **Плевок** — §7.1. **Трофей** — §7.2.
6. Когда `closes_at` наступил или вручную закрыто: `status=closed`. Сообщение редактируется на `🕊 Голубь улетел. Попаданий: N.` `pigeon.state = away`. Ставки рассчитываются (§7.4). Проверяются ачивки.
7. Дашборд обновляется (§8).

## 7. Механики

### 7.1 Плевок (`hit`)

- Нажатие `💦 Плюнуть` на открытом event.
- Один плевок на пользователя на event (`UNIQUE`).
- +1 очко в ledger.
- Ответ — короткий `answerCallbackQuery`: «💦 Попал!». Новых сообщений в чат нет.

### 7.2 Золотой помёт (трофей)

- Трофей переходит к участнику, который **первым** попал в каждом event. Так меньше шума, чем при каждом попадании. (Открытый вопрос §15.)
- Владелец держит трофей до следующего перехода. Дни владения копятся через `trophy_log`.
- В дашборде: `🏆 Золотой помёт: Имя (держит N дн.)`.
- Ачивка «Держатель трофея» (§7.6) за суммарное владение ≥ 7 дней.

### 7.3 Дартс (`dart`)

- Нажатие `🎯 Дартс` на открытом event.
- Бот отправляет `sendDice(emoji='🎯')` ответом на сообщение event. Значение берём из результата.
- Один бросок на пользователя в сутки (`local_day` по timezone чата).
- Очки: `6 → 3`, `5 → 2`, `4 → 1`, `1–3 → 0`. Запись в `dart_throws` и ledger.
- Значение 6 даёт ачивку «В яблочко» (§7.6).

### 7.4 Ставки (`bet`)

- Нажатие `💰 Ставка` открывает два варианта: `Будет ≥ 3 плевков` / `Будет < 3`. Порог в конфиге.
- Ставка фиксированная: 1 очко. Выигрыш: 2 очка (стейк + 1). Проигрыш: стейк списывается.
- Ставить можно только при балансе ≥ 1 и только на открытом event. Одна ставка на event.
- При закрытии event: сравниваем количество `hits` с порогом. Выигравшие получают выплату, проигравшие — ничего. Записи в ledger с `bet_stake` и `bet_win`.

### 7.5 Дуэль (`duel`)

- `/pigeon duel` в ответ на сообщение соперника или `/pigeon duel @username`.
- Одна активная дуэль на чат. Ожидание принятия 10 минут.
- Соперник принимает кнопкой `✅ Принять`. Отклонить — `❌ Отказаться`. Нажимать может только соперник.
- Не принял за 10 минут → `expired`, без очков.
- Бой: 3 раунда. Каждый раунд бот бросает `🎯` каждому участнику и сравнивает значения. Ничья — ещё раунд.
- Победитель: +3 очка (`duel_win`). Проигравший — 0.
- Итог пишется в чат одним сообщением с построчными результатами.

### 7.6 Достижения (`achievements`)

Выдаются один раз на `(chat_id, user_id, code)`. Оценка — после релевантных событий.

| Код | Условие | Название |
|---|---|---|
| `sniper` | 5 попаданий подряд в 5 последовательных прилётах | Снайпер |
| `early_bird` | Первый плевок в 5 прилётах | Ранняя пташка |
| `bullseye` | Бросок дартса со значением 6 | В яблочко |
| `trophy_holder` | Суммарно ≥ 7 дней держал трофей | Держатель трофея |
| `duelist` | Первая выигранная дуэль | Дуэлянт |
| `friend` | 0 попаданий за месяц при ≥ 5 прилётах | Голубиный друг |

Тексты — в `content/achievements.yaml`. Код ачивки — в `services/achievements.py`.

### 7.7 Общий квест (`quest`)

- Раз в неделю (понедельник 00:00 по timezone чата) создаётся квест: `target = 20` попаданий. Значение в конфиге.
- Прогресс = попаданий за неделю по всем участникам.
- В дашборде: `🎯 Квест недели: ▓▓▓▓░░░░ 8/20`.
- Выполнен — голубь получает титул (например, «Почётный»). Титул отображается в дашборде. Очков не даёт.
- Квест не выполнен к концу недели — `failed`, без последствий.
- Сообщение о результате — плановое, без бюджета (§9).

### 7.8 Голосование за имя (`name_vote`)

- Первого числа каждого месяца — опрос из 5 имён, которые ещё не использовались (`content/names.yaml`).
- Опрос закрывается через 24 часа. Победитель становится именем голубя. Старое имя уходит в `name_history`.
- Ничья — случайный выбор среди лидеров.
- Админ может запустить вручную: `/pigeon name`.

### 7.9 Сериал «Жизнь голубя» (`series`)

- Раз в неделю (вторник 12:00 по timezone чата) публикуется эпизод из `content/series.yaml`: 3–4 строки текста и опрос «Что дальше?».
- Каждый эпизод содержит 2–3 варианта продолжения. Варианты — ключи, ведущие к следующему эпизоду. Так история ветвится по выбору чата.
- Опрос закрывается через 24 часа. Выбранный вариант определяет следующий эпизод. Ничья — случайный выбор.
- Конец ветки — возврат к стартовому эпизоду следующего «сезона».
- Контент пишется вручную. LLM не нужна.

### 7.10 Календарь (`anniversary`)

- Дата первого прилёта (`pigeon.born_at`) — день рождения голубя.
- В годовщину — событие «День рождения голубя». Очки за плевки в этот день ×2.
- Спонтанное сообщение, проходит через бюджет.

### 7.11 Предсказание (`fortune`)

- `/pigeon fortune` — один раз в сутки на участника.
- Случайное предсказание из `content/fortunes.yaml`. Очков не даёт.
- Ответ только запросившему — через reply на его команду, без нового спонтанного сообщения.

### 7.12 Голубиная почта (`mail`)

- Редко (не чаще раза в месяц). Спонтанное сообщение, проходит через бюджет.
- Загадка из `content/riddles.yaml` и 3 варианта кнопками. Один правильный.
- Правильный ответ: +2 очка (`mail`). Ответы принимаются 24 часа.

### 7.13 Фото-голубь (`photo_poll`)

- Триггер: фото с подписью, содержащей «голубь» или 🕊 (нужен privacy mode off, §2), либо `/pigeon photo` в ответ на фото.
- Бот отправляет опрос «Это голубь или ворона?» с вариантами `Голубь` / `Ворона` / `Не знаю`.
- Очков нет. Не чаще раза в час на чат. Считается пользовательским действием, в спонтанный бюджет не входит.

### 7.14 Погода (`weather`) — фаза 4

- В 08:00 по timezone чата запрашивается прогноз (API без ключа, например Open-Meteo). Нужна локация чата в `/pigeon setup`.
- При дожде: сообщение «🌧 Голубь сидит дома», прилёт на сегодня отменяется. Сообщение — спонтанное, проходит через бюджет.
- Фича опциональная. Если локация не задана, не работает.

## 8. Дашборд

Одно закреплённое сообщение на чат. Его `message_id` хранится в `chats.dashboard_message_id`.

```
🕊 Голубь: Витёк (3-й по счёту)
Статус: сидит на подоконнике
🏆 Золотой помёт: Имя (держит 2 дн.)
🎯 Квест недели: ▓▓▓▓░░░░ 8/20 · титул: Почётный
📊 Топ недели: Имя 12 · Имя 9 · Имя 4
```

- Обновляется после каждого события и не чаще раза в минуту.
- Если сообщение удалено или не найдено — создаём новое и закрепляем.
- Имена — текстом, без пингов.

## 9. Бюджет и анти-шум

**Спонтанные сообщения** — те, что бот публикует по событию, а не по запросу:
- прилёт (`arrival`);
- почта (`mail`);
- погода (`weather`);
- годовщина (`anniversary`).

**Лимиты (на чат):**
- спонтанных — не больше 1 в сутки и 3 в неделю;
- при превышении job переносится на следующий слот.

**Плановые сообщения** — сериал, имена, итоги квеста, недельная статистика. Каждый тип не чаще раза в неделю. В спонтанный бюджет не входят.

**Пользовательские действия** — кнопки, `/pigeon ...`. Не лимитируются по чату. По участнику:
- дартс — 1 бросок в сутки;
- предсказание — 1 в сутки;
- дуэль — одна активная на чат.

**Тихие часы** — по умолчанию 23:00–09:00 по timezone чата. Бот ничего не публикует сам. Кнопки и команды работают.

**Живой чат** — см. §6, пункт 3. Учитываются только метаданные: количество сообщений по минутам, без текста.

**Пауза.** `/pigeon pause 24h | 7d | off` — админ. Во время паузы бот ничего не публикует сам, включая плановые.

**Без пингов.** Имена в сообщениях — текст. Бот не использует mention-сущности.

## 11. Callback data

Формат: `pg:<action>:<id>[:<arg>]`. Всегда ≤ 64 байт.

| Action | Пример | Что делает | Кто может |
|---|---|---|---|
| `hit` | `pg:hit:123` | Плевок | все |
| `dart` | `pg:dart:123` | Дартс | все |
| `bet` | `pg:bet:123:y` / `pg:bet:123:n` | Ставка | все |
| `duel_ok` | `pg:duel_ok:45` | Принять дуэль | только соперник |
| `duel_no` | `pg:duel_no:45` | Отказаться | только соперник |
| `mail` | `pg:mail:67:2` | Ответ на загадку | все |

Обработчик проверяет: событие открыто, пользователь ещё не действовал (если это предусмотрено), у него есть право.

## 12. Конфиг и контент

**Переменные окружения:**
- `PIGEON_BOT_TOKEN` — токен бота;
- `PIGEON_DB_PATH` — путь к SQLite, по умолчанию `./data/pigeon.db`;
- `PIGEON_LOG_LEVEL`.

**Настройки механик** — `config/defaults.yaml`:
- окно прилёта, длительность события (60 мин);
- порог живого чата (5 сообщений за 10 мин), макс. переносов (2);
- порог ставки (3), стейк (1);
- цель квеста (20);
- очки за дартс и дуэль;
- лимиты бюджета;
- тихие часы по умолчанию.

**Контент** — `content/*.yaml`. Тексты, сериал, имена, предсказания, загадки, ачивки. Меняется без правки кода.

## 13. Тестирование

- **Сервисы** — юнит-тесты без Telegram: ledger, ачивки, бюджет и переносы, расчёт ставок, раунды дуэли, прогресс квеста, ветвление сериала.
- **Репозитории** — тесты на временной SQLite.
- **Telegram-адаптер** — подменяется фейком в тестах.
- **Время** — через clock, никаких реальных задержек.
- **Ручной смоук** — тестовый чат с двумя аккаунтами: прилёт, плевок, дартс, ставка, дуэль, закреп.

## 15. Открытые вопросы

Ниже — рабочие решения по умолчанию. Их можно поменять.

1. **Трофей переходит при первом попадании в event или при каждом?** По умолчанию — при первом (меньше шума).
2. **Порог ставки** — 3 попадания. Подходит ли для чата на 6 человек, или нужно 2?
3. **Цель квеста** — 20 попаданий в неделю. Для тихого чата может быть много; возможно, 10.
4. **Privacy mode off** — нужен для фото и слова «голубь». Раскрыто в `/pigeon help`. Приемлемо?
5. **Язык** — русский для всех текстов бота.
