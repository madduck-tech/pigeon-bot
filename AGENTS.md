# Инструкции для агентов

Основные правила проекта находятся в [CLAUDE.md](CLAUDE.md) и обязательны для любого harness.

Перед началом работы также прочитай [процесс разработки](docs/development-flow.md). Локальные заметки, если они есть, находятся в `CLAUDE.local.md` и не попадают в git.

Универсальные навыки хранятся в `.agents/skills/`. Каталог `.claude/skills/` содержит копии для совместимости с Claude; при изменении навыка обе копии должны оставаться одинаковыми.
